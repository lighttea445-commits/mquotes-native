# memory.md — Preferences

## Communication

- Draft before creating — always show written content for approval before writing the file
- No emoji in responses or files
- Short and direct — skip preamble, summaries, and filler
- Don't restate what was just said, just act

## Code Behavior

- Commit to GitHub after every update
- Read ALL relevant files before editing — get the whole picture first
- Change only what the task requires — no refactors, no extra comments, no speculative additions
- No `preview_start` or browser preview tools — this is a native Android app verified on device

## Design

- Platform: Android only
- New Architecture is enabled (`newArchEnabled: true`) — the CLAUDE.md note saying otherwise is outdated
- Design tokens only — colors from `theme.*`, no hardcoded values
- Gold accent: `#B8975A`
- Fonts: Playfair Display for quotes, Inter for UI
- All modals open as inline `BottomSheet` via `ModalContext` — no push navigation for overlays

## Product

- App name: **Quotable**
- Premium minimalist motivation app — the aesthetic is elevated and calm, not loud or gamified
- No dark patterns, no pushy behavior — user trust is the priority
